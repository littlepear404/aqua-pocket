# AQUA · 掌心水压套圈

可本地运行的 3D 掌上水压套圈游戏。Three.js 渲染，Rapier WASM 刚体物理。

在线试玩：[GitHub Pages](https://littlepear404.github.io/aqua-pocket/)

## 启动

在此目录用 PowerShell 执行：

```powershell
npm install
npm run dev
```

浏览器打开终端显示的本地地址，默认 http://127.0.0.1:5173 。需要支持 WebGL 2 的现代浏览器。不需要账号或服务端。

```powershell
npm test
npm run build
```

`dist` 是生产静态站点，需要通过 HTTP 服务访问，不应直接双击 HTML。依赖已在构建中打包；在线字体不可用时自动使用系统字体。

## 跨平台与手机体感

本项目是纯前端静态应用，无后端、数据库或服务器运行时要求。Windows、macOS、Linux 使用支持 WebGL 2 的浏览器运行；手机提供触屏按钮、双指同时喷水、三档力度及横竖屏布局。粗指针设备限制渲染像素比为 1.5，保留固定步长物理。

1. 手机上通过 **HTTPS** 打开网站，点击「启用手机体感」。iOS 等需要授权的浏览器会请求运动与方向权限；未需要授权接口的浏览器直接等待数据。
2. 体感使用真实重力，不把初始握姿重新定义为竖直：竖握时圆环下沉，侧倾时滑向低侧，倒置时落向顶部，平放时沉向屏幕背面。实时文字显示重力方向和偏离竖直的角度。「刷新姿态」只重置平滑滤波，不改变物理竖直方向。
3. 晃动使用 `DeviceMotionEvent.acceleration`（不含重力）。只有提供有效加速度的设备才能体感晃动；否则继续使用 Q/E 或屏幕晃动按钮。
4. 屏幕横竖切换时只转换屏幕坐标，不重新归零。体感中虚拟外壳保持可读，避免屏幕与外壳双重旋转。拖动机身、调整滑块或方向键会切回手动模式，重新开始也关闭体感。体感中的「归正」仅刷新当前真实姿态，手动模式中才恢复虚拟机身直立。
5. 关闭体感会移除传感器监听；后台与帮助弹窗暂停体感作用。不支持、拒绝权限、非安全环境或 5 秒内无姿态数据时，会给出说明并保留手动玩法。

普通手机触屏通常没有可用的压力数据，因此使用三档水压；笔压仍由支持的触控笔提供。传感器数据仅用于本地游戏，不上传。

### 静态部署与局域网调试

将 `npm run build` 生成的 **dist 文件夹全部内容**上传到任意 HTTPS 静态托管；资源采用相对路径，可部署在域名根目录或子目录。无需 SPA 路由回退配置。未注册离线 Service Worker。

本仓库通过 GitHub Actions 发布到 GitHub Pages：推送到 `main` 后自动运行 `npm ci`、`npm test` 和 `npm run build`，通过后上传 `dist` 并部署。也可在 Actions 中手动运行 `Deploy GitHub Pages`。Pages 使用 HTTPS，可用于手机体感试玩。

同一 Wi-Fi 下触控调试可运行 `npm run dev -- --host 0.0.0.0`，用手机访问电脑局域网 IP。**普通局域网 HTTP 地址不能作为体感验证环境**：需受手机信任证书的 HTTPS 服务或 HTTPS 静态站点。手机上的 localhost 指向手机自身，不能访问电脑服务。

优先使用系统 Safari / Chrome 等浏览器；内嵌浏览器或 iframe 可能限制传感器。若必须嵌入 iframe，宿主还需要相应的 accelerometer / gyroscope Permissions Policy。真实硬件支持与权限策略以浏览器为准。

API 依据：[MDN 姿态事件](https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent)、[MDN 运动授权](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static)。

## 操作

- **A / D** 或左右按钮：对应喷水口泵水。按住连续泵水，每侧独立限制为至少 0.2 秒一次，支持同时泵水。
- **Shift**：加强；**Shift + 空格**：最强。界面提供轻柔、标准、强劲三档基础水压。触控笔以笔压控制强度。
- **拖动机身 / 两个角度滑块**：360° 调整重力方向。方向键微调，归正按钮恢复直立。
- **Shift + 拖动**：按拖动速度产生晃动力；普通快速拖动也带来惯性。
- **Q / E**：轻晃 / 用力晃。
- **侧面观察**仅移动观察相机，不改变重力；滚轮缩放。
- 八枚圆环同时套在任意两根柱子上并保持 0.75 秒即获胜。圆环始终保持物理活动，倾倒或水流可使其脱落。

## 物理模型与边界

- 8 个有体积的圆环，每环由 24 个相接的胶囊碰撞体组成，保留真实中心孔；2 根实体柱子；6 面封闭容器。
- 固定 120 Hz 物理步长，连续碰撞检测，环之间、环与柱、环与壁之间的三维碰撞与摩擦。
- 密度差对应的有效重力模拟浮力；基于相对水流速度的阻力，偏心作用力产生翻滚；喷口使用时间衰减、径向扩散的局部水流场。
- 本项目是**实时水动力近似**，不是完整 Navier–Stokes / CFD 流体求解，没有模拟水的自由液面（容器满水）或真实材料实验标定。
- 获胜通过柱轴与圆环平面交点、环内孔空间及柱高判定，没有吸附或把圆环锁定在柱子上的辅助。
- 物理时间跟随固定步进；后台标签与帮助弹窗暂停，严重掉帧时减慢以保持稳定。

物理 API 参考：[Rapier 官方文档](https://rapier.rs/docs/user_guides/javascript/rigid_body_forces_and_impulses/)。
